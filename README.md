## Déploiement
Configurer une base Postgres compatible Vercel, exécuter db/schema.sql, puis définir POSTGRES_URL, AUTH_SECRET, ADMIN_KEY et NEXT_PUBLIC_APP_URL. Déployer ensuite sur Vercel.
